Turning vendor manuals into wireable data

Terminal wiring for third-party equipment lives buried in PDF manuals — read once by hand, then retyped into a spreadsheet, page after page. This tool reads the manual directly and produces a structured connection table ready to feed into wire mapping.

Pipeline

How it works

Four stages, each handling one part of what used to be a single manual task.

01

Ingest

Load the vendor PDF and split it into individual pages for processing.

02

Read

Pass each page image to a vision model with a prompt targeted at terminal blocks and pin tables.

03

Structure

Normalize the model's output into a consistent schema — terminal, wire, signal, destination.

04

Map

Hand the structured table to the wire-mapping step for cross-referencing against the panel design.

Under the hood

A simplified view of the extraction loop — one call per page, validated against an expected schema before it's accepted.

extract.pyillustrative

for page in manual.pages:
    image = render(page)
    result = vision_model.extract(
        image=image,
        schema=TerminalConnection,  # terminal, wire, signal, destination
    )
    connections.extend(result.validated())

write_table(connections, out="wire_map.csv")
