Catching what changed between drawing revisions

Reviewing a new drawing package revision by eye means scanning dozens of pages hoping to spot what moved. This tool merges two revisions of a drawing package and produces a single overlay that highlights exactly what was added, removed, or modified — plus a structured change log to review against.

How it works

Four stages, from raw PDFs to a reviewable change log.

01

Load

Open both drawing package revisions and match corresponding pages between them.

02

Render

Rasterize each matched page pair to images at a consistent resolution for comparison.

03

Diff

Run a pixel-level comparison between the two renders and cluster the differences into regions.

04

Classify

Sort each changed region into added, removed, or modified, and log it against the drawing reference.

Under the hood

A simplified view of the merge-and-diff loop — visual comparison first, then classification of what changed.

diff.pyillustrative

import fitz, cv2  # PyMuPDF, OpenCV

rev_a = fitz.open("rev3.pdf")
rev_b = fitz.open("rev4.pdf")

for page_a, page_b in align_pages(rev_a, rev_b):
    img_a, img_b = render(page_a), render(page_b)
    diff_mask = cv2.absdiff(img_a, img_b)
    regions = cluster_regions(diff_mask)
    changelog.extend(classify(regions))  # added / removed / modified

write_overlay(img_b, changelog, out="overlay.pdf")
